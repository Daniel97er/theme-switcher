# Theme Switcher

A lightweight, reusable website theme switcher built with HTML, CSS, and vanilla JavaScript.

## Features

- Seven themes: Standard, Light, Dark, Halloween, Christmas, Space Blue, and Green Gibberish (Only Green as Name was too boring)
- Custom theme selection menu
- CSS custom properties for theme styling
- No external libraries or frameworks required

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Select a theme to change the website's appearance.

## Integration

To use the theme switcher in an existing website:

1. Add the relevant HTML from `index.html`.
2. Integrate the theme styles from `styles.css`.
3. Adapt the theme-switching logic from `script.js`.
4. Replace relevant hard-coded colors with CSS custom properties.

Some adjustments may be necessary to match your website's existing structure and styles.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
